设计规范怎样改变了测评 Lab？

选择一个页面，查看同一任务的两种布局。左图来自旧版 Lab 的实际窗口，保留了侧栏，右图来自新版内容区，使用演示数据。

怎样知道下一步该做什么？

第一次打开测评页，音频、工作簿和模型都尚未选择。

页首给出一个主操作

旧版把 Start Run 放在第三组，下方还有尚不可用的暂停、继续和取消。新版把 Start run 放到标题旁，未配好时写明先选择音频文件夹。

配置就绪后，同一个位置显示本次要跑的录音数。开始后，进度和控制会滚入视野。

就绪时，主操作怎样变化？

数据配好后，页首显示有 24 条录音可以测评，Start run 变为可用。

怎样确认按钮会操作哪个模型？

旧图中 Parakeet 已安装，Qwen3-ASR 尚未下载。新图以 Parakeet 和两款其他模型展示型号、状态和操作的排列。

列表按操作对象分组

旧版已经分别列出 Model size 和 On disk。全库删除在页首，单项删除在每行右端。新版保留这两个容量读数，把单项操作并排放在型号下，把全库删除收进 Advanced model tools。

辅助功能中的下载按钮也读得出具体型号。在窄窗中，状态和操作可以分行排列。

窄窗里怎样区分下载量和磁盘占用？

在八款模型的集成实例中，Whisper Large v3 Turbo 的完整下载约为 1.62 GB，尚未安装时占用为 0 kB。此图使用真实模型清单与模拟下载状态。

哪个资源包正在影响测评？

旧窗口只有一个导入包，它同时出现在 Pack in Use 和 Imported Packs。新版示例使用两个包，便于观察当前版本和可切换版本的区别。

区分页面操作和条目操作

旧版把一个导入按钮放在当前包与已导入列表之间。新版把 Import resource pack 提到页首，第一张卡直接回答当前在用哪个版本。

列表把每个版本的来源、使用状态和切换操作放在一起，点击 Use 前可以就地核对。

看看 360 pt 窄窗中的资源包

宽度收紧后，导入按钮转到标题下方。当前包仍是第一张卡，切换动作仍跟随对应版本。

怎样从一条历史记录继续操作？

旧窗口列出七次已完成的运行，每次处理一条录音。新版示例另外展示中断、取消和文件夹缺失，便于查看不同状态下可用的操作。

让状态和下一步操作相邻

旧版用六列排列记录，开始时间已经被截断。新版以运行名称为标题，在同一组内放入时间、带单位的计数和可用操作，中断项可以直接点 Resume。

取舍也能从图中看出。新版一条记录占用更多纵向空间。旧表格更紧凑，便于横向对齐数字。

看看 360 pt 窄窗中的历史记录

宽度不足时，名称、状态和动作换行。中断或文件夹缺失都有文字说明，颜色只作辅助。

把设计要求变成可以检查的行为

三个文件按钮，各有名字

此前测试环境中的旧版内容区，三个文件选择按钮在 macOS 辅助功能树中都叫 Choose…。新版分别标识音频文件夹、工作簿和输出文件夹。宽窗和 360 pt 窄窗均已核对名称和启用状态。

启动后看得见进度

在 640 × 680 pt 窗口放入 24 条录音和 8 条提示。触发开始后，新版自动回到进度和控制所在的位置。后续进度更新不会反复把用户拉回页首。

第二次打开也能回到结果

打开一条历史结果，滚回列表，再打开同一条。独立验证中，两次都回到结果区，汇总只读取一次。布局审查也检查了这样的重复操作。

四张旧版图片均为原始窗口截图，保留原始尺寸和侧栏。新版图片由实际编译的 SwiftUI 内容区渲染，主图宽 780 pt、高 720 pt。两侧的型号、资源包和运行记录可能不同。设计规范为页标题、主次按钮、组间距、卡片和语义色提供依据。启动后滚动与重复打开结果属于本次实现中验证的交互。此案例未测量用户完成任务所需的时间。
